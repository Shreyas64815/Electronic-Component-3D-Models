# Electronic Component 3D Models

A growing collection of accurate 3D CAD models of electronic components created in Fusion 360.

## About

This repository contains 3D models of commonly used electronic components for mechanical design, PCB enclosure design, and product development.

Each component includes:

- Fusion 360 source file (.f3d)
- STEP file (.step)
- Preview image
- Datasheet reference (when available)

## Categories

- Sensors
- Microcontrollers
- Communication Modules
- Displays
- Motors
- Connectors
- Power Modules
- Miscellaneous

More components will be added regularly.
