## Overview

An accurate 3D CAD model of a **2-Pin Rocker Switch (ON/OFF)**, created in **Autodesk Fusion 360** using dimensions referenced from manufacturer documentation and available technical references.

This model is suitable for:

- PCB assembly visualization
- Enclosure design
- Mechanical integration
- Product prototyping
- Engineering education
