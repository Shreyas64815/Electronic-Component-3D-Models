## Overview

An accurate 3D CAD model of the **Momentary Push Button Switch**, created in **Autodesk Fusion 360** using dimensions referenced from the manufacturer's datasheet.

This model is suitable for:

- PCB assembly visualization
- Enclosure design
- Mechanical integration
- Product prototyping
- Engineering education
