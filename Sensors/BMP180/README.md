## Overview

An accurate 3D CAD model of the **BMP180 Pressure Sensor Module**, created in **Autodesk Fusion 360** using dimensions referenced from the manufacturer's datasheet.

This model is suitable for:

- PCB assembly visualization
- Enclosure design
- Mechanical integration
- Product prototyping
- Engineering education

---

## Specifications

| Property | Value |
|----------|-------|
| Component | BMP180 Pressure Sensor Module |
| Interface | I²C |
| Pin Count | 4 |
| Pins | VCC, GND, SDA, SCL |
| CAD Software | Autodesk Fusion 360 |
| File Formats | STEP, STL |
